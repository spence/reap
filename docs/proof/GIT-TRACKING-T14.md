# Bound native Git tracking

## Delivered boundary

Internal read-only Files determines declaration tracking from a bound Git index snapshot.
It starts no Git process and changes no repository file.
Metadata reads require native identity and the worker's physical grant.
Index bytes, expanded paths, and parser capacity share the preview allocation budget.

The reader supports SHA-1, SHA-256, and index versions 2–4.
Every conflict stage and intent-to-add entry counts as tracked.
Native file identity resolves case and Unicode aliases.
Tracked declarations remain inert; preservation roles retain their separate veto.

Optional index caches never enter the Gitoxide decoder.
Nonzero checksums cover the complete original index before cache omission.
Required extensions, split indexes, sparse indexes, configuration includes, and unknown repository extensions refuse tracking.
Publication revalidates index sources, checkout bindings, alias observations, and missing discovery markers.
Unknown evidence protects the selection.

Tracking does not establish Git recovery.
No public Files job route, applying route, migration, or conversation-source release is activated.
